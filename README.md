🔧 Featured Project: Airtable → Power BI Automation Connector

The problem: Inata's Power BI dashboards were quietly wrong. Reports pulled from static Excel exports on SharePoint instead of live Airtable data — meaning every dashboard number was a stale snapshot, not reality.

What I found:

A data integrity bug that had inflated reported revenue by roughly 3×
19 overdue orders that an existing Airtable formula had already flagged, but that no dashboard ever surfaced

What I built:

A custom Airtable-to-Power BI connector combining Make workflows and Python scripting
Pagination logic to extract and sync records across 15+ linked tables (quotes, clients, invoicing, orders)
DAX measures and Power Query (M) transformations to align sales, quotation, and invoicing data in real time

Impact: Replaced a manual, error-prone export process with a live, repeatable pipeline — and turned invisible risk into visible, actionable data for the team.

Tech stack: Airtable API · Make · Python · Power BI · DAX · Power Query (M)
